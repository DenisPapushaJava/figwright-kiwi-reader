# FigLens

Читает выбранный фрейм Figma из Chrome и передаёт его Codex, Claude Code, Cursor
или другому MCP-клиенту. Работает локально, не изменяет макет, не требует Figma-токена.

[Скачать релиз](https://github.com/DenisPapushaJava/figwright-kiwi-reader/releases/latest)

## Возможности

- Размеры, auto-layout, тексты, цвета и свойства компонентов.
- Экспорт доступных SVG и исходных изображений.
- Поиск подходящих компонентов, иконок и цветовых токенов в коде проекта.
- Сравнение изображения макета с реализацией.

## Установка

Готовый установщик — для Windows. Нужны Chrome 116+ и Node.js 24.11+ из ветки 24 или Node.js 26+.

1. Скачайте ZIP из релиза, распакуйте и откройте папку `figlens`.
2. Запустите в PowerShell:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\install.ps1
   ```

3. В `chrome://extensions` включите **Режим разработчика** → **Загрузить распакованное расширение**.
   Выберите `%LOCALAPPDATA%\FigwrightKiwi\extension`.
4. Перезапустите MCP-клиент.

Установщик настраивает доступные Codex, Claude Code и Cursor. Для одного клиента:
`.\install.ps1 -Clients Codex`.

## Использование

1. Откройте Figma в Chrome и выберите фрейм или слой.
2. В расширении FigLens нажмите **Подключить макет**. Вкладка перезагрузится.
3. Дождитесь зелёного индикатора и отправьте запрос, например в Codex:

   ```text
   @fl прочитай выбранный фрейм
   @fl подготовь выбранный фрейм к реализации в текущем проекте
   ```

Сервер передаёт клиенту стартовые инструкции. Для явного запуска доступны MCP-промпты
`figlens_codex`, `figlens_claude` и `figlens_cursor`, если клиент поддерживает меню промптов.

Для другого слоя достаточно изменить выделение в Figma. Если экран ещё не прочитан,
откройте его и нажмите **Обновить данные**. Для фотографий включите
**Сохранять исходные изображения** перед обновлением данных.

## Обновление и удаление

Запустите установщик из нового релиза, обновите FigLens в `chrome://extensions`
и перезапустите MCP-клиент. При обновлении с 0.5.x подключение `fk` заменяется на `fl`.

Удаление:

```powershell
powershell -ExecutionPolicy Bypass -File "$env:LOCALAPPDATA\FigwrightKiwi\uninstall.ps1"
```

## Если не работает

- Нет подключения — запустите MCP-клиент и снова нажмите **Подключить макет**.
- Нужен перезапуск расширения — нажмите **Обновить** в `chrome://extensions`.
- Не хватает данных — откройте нужный экран и нажмите **Обновить данные**.
- Для разбора ошибки скопируйте диагностику из панели FigLens.

FigLens получает только данные, которые Figma передала открытой вкладке. Большие экраны
читаются по секциям. Изменения внутреннего протокола Figma могут потребовать обновления FigLens.
